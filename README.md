# Heart Disease Prediction System

## Project Summary

The Heart Disease Prediction System is a Machine Learning-based healthcare application designed to predict the likelihood of heart disease using patient medical data. The system analyzes various health parameters such as age, gender, blood pressure, cholesterol level, blood sugar, chest pain type, ECG results, and heart rate to determine whether a patient is at risk of heart disease.

This project utilizes data preprocessing, exploratory data analysis (EDA), feature selection, and multiple machine learning algorithms including Logistic Regression, Decision Tree, Random Forest, Support Vector Machine (SVM), and K-Nearest Neighbors (KNN). The models are evaluated using performance metrics such as Accuracy, Precision, Recall, F1-Score, and ROC-AUC to select the best-performing model.

The primary goal of this project is to assist healthcare professionals in early diagnosis and decision-making while helping patients understand their health risks and take preventive measures. By combining healthcare data with machine learning techniques, the system provides a fast, cost-effective, and reliable solution for heart disease prediction.

### Key Features

* Heart disease risk prediction
* Multiple machine learning model comparison
* Data preprocessing and feature engineering
* Performance evaluation using standard metrics
* User-friendly prediction dashboard
* Decision support for healthcare professionals

### Expected Outcome

The system aims to improve early detection of heart disease, identify major risk factors, and support timely medical intervention, ultimately contributing to better healthcare outcomes.
